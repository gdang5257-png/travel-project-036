  • ตรวจสอบเวลาเปิดและวันหยุดจากผู้ดูและสถานที่

  • ตรวจสอบจุดจอดรถหรือจุดลงรถโดยสาร

เขาช่องกระจก

ข้อมูลสำคัญ

  • ลักษณะ ภูมิประเทศ : เป็นภูเขาขนาดย่อมสูงประมาณ 245 เมตรจากระดับน้ำทะเล ( หรือ ประมาณ 94 เมตรจากพื้นราบใกล้ชายฝั่ง)

  • ที่มาของชื่อ : บริเวณด้านทิศเหนือของภูเขามีช่องทะลุโปร่งมองดูคล้ายกับกรอบของกระจก

  • การเดินทางขึ้นไปด้านบน : : ต้องเดินขึ้นบันไดคอนกรีตจำนวน 396 ขั้น

  • เวลาปิดทำการ : : เปิดให้เข้าชมทุกวัน เวลา 05.00 - 20.00 น.

      • สิ่งที่น่าสนใจบนเขาช่องกระจก

      • วัดธรรมิการามวรวิหาร : ตั้งอยู่บริเวณเขาช่องกระจกเป็นที่ประดิษฐานรอยพระพุทธบาทจำลอง และพระบรมสารีริกธาตุ

      • ต้นพระศรีมหาโพธิ์ : พระบาทสมเด็จพระบรมชนกาธิเบศรมหาภูมิพลอดุลยเดชมหาราชบรมนาถบพิตรได้เสด็จฯ มาทรงประกอบพิธีบรรจุพระบรมสารีริกธาตุและทรงปลูกไว้เมื่อวันที่ 12 มิถุนายน 2501 ( มีงานฉลองในวันที่ 12 มิถุนายนของทุกปี )

      • จุดชมวิว 360 องศา : :สามารถมองเห็นทัศนียภาพของตัวเมืองประจวบคีรีขันธ์และเห็นโค้งอ่าวสำคัญทั้ง 3 อ่าว คือ อ่าวประจวบ อ่าวมะนาว และอ่าวน้อย

      • ถ้ำเทวาสถิตย์ & จุดชมพระอาทิตย์ขึ้น : : เป็นจุดชมแสงแรกและพระอาทิตย์ขึ้นยามเช้าที่สวยงามโดยพระอาทิตย์จะขึ้นตรงบริเวณช่องเขาพอดี

ศาลหลักเมืองประจวบคีรีขันธ์

  • ที่ตั้ง : ถนนสละชีพตำบลประจวบคีรีขันธ์อำเภอเมืองประจวบคีรีขันธ์ ( ตรงข้ามศาลากลางจังหวัดประจวบคีรีขันธ์และใกล้กับเขาช่องกระจก )

  • เวลาทำการ : เปิดทุกวันตั้งแต่เวลา 08:00 - 19:00 น.

  • สถาปัตยกรรม : : เป็นอาคารทรงจตุรมุขยอดปรางค์ 9 ชั้นงดงามด้วยศิลปะแบบลพบุรีผสมผสาน

  • องค์หลักเมือง ( นาม " จตุ โชค ") :

    • ทำจากไม้ตะเคียนที่ได้มาจากอำเภอกุยบุรี
    • ส่วนยอดแกะสลักเป็นศิลปะศรีวิชัย 4 เศียร 4 พักตร์ ลงรักปิดทองและประดับอัญมณี
    • มี ขนาด ความ สูง 2.74 เมตร เส้น ผ่าน ศูนย์กลาง 0.37 เมตร

      • ประวัติการสร้าง :

        • วางศิลาฤกษ์เมื่อวันที่ 4 มีนาคม พ.ศ. 2536 ในสมัยที่ร้อยตำรวจเอก อำนวย ไทยานนท์ เป็นผู้ว่าราชการจังหวัด
        • พระบาทสมเด็จพระบรมชนกาธิเบศรมหาภูมิพลอดุลยเดชมหาราชบรมนาถบพิตรทรงพระกรุณาโปรดเกล้าฯ ให้ประกอบพิธีทรงสุหร่ายและเจิมยอด เมื่อวันที่ 8 ธันวาคม พ.ศ. 2536
        • สมเด็จพระบรมโอรสาธิราชฯ สยามกุฎราชกุมาร ( พระอิสริยยศในขณะนั้น ) เสด็จพระราชดำเนินแทนพระองค์มาทรงประกอบพิธีเปิดศาลหลักเมืองอย่างเป็นทางการ เมื่อวันที่ 20 สิงหาคม พ.ศ.2537
